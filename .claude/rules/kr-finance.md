# Rule: KR 증권 컨벤션

Tickr는 한국 사용자 대상 모의투자 앱이다. 다음 컨벤션을 따른다.

## 1. 시장 컬러

- **상승 = 빨강(`up`)**, **하락 = 파랑(`down`)**, 변동 없음 = 회색(`flat`)
- 미국식(상승=초록) **절대 금지**.
- 색상만으로 의미 전달 금지. 화살표 `▲▼`와 함께 사용.

## 2. 가격 표기

- KRW: `₩` 접두 + 천단위 콤마 + 정수. 예: `₩72,400`
- USD: `$` 접두 + 소수 2자리. 예: `$185.20`
- 가격/등락 텍스트는 항상 `tabular-nums`.

포매팅 헬퍼: `shared/lib/format.ts`
```ts
formatPrice(72400, 'KRW') // '₩72,400'
formatPrice(185.2, 'USD') // '$185.20'
formatChange({ delta: 1200, ratio: 0.0169 }) // '▲ 1,200 (+1.69%)'
```

## 3. 등락 표시

```
₩72,400          ← color: up/down/flat (전일 대비)
▲ 1,200 (+1.69%) ← 동일 색상, 화살표 포함
```

`+`/`-` 부호 명시. 0%일 때는 `-` 표시 (또는 `flat`).

## 4. 종목 식별

- 한글 이름 우선, 종목코드 `mono-sm`으로 보조.
- KR: `삼성전자` + `005930`
- US: `Apple Inc.` + `AAPL`
- 시장 뱃지(KR/US)는 해외 종목 또는 혼합 리스트에서만.

## 5. 호가창 표시 금지

**호가창(orderbook)을 화면에 표시하지 않는다.**

- 사용자는 가격을 **직접 입력**(지정가) 또는 **현재가로 즉시 체결**(시장가) 중 선택.
- KIS 호가 API 호출도 하지 않음 (불필요한 트래픽).
- 라이선스/표시 정책 위험 최소화.

## 6. 주문 유형

| 유형 | 동작 | UI 표시 |
|---|---|---|
| MARKET (시장가) | 현재 KIS 시세로 즉시 체결 | "현재가로 즉시 체결" 안내, 가격 입력 비활성 |
| LIMIT (지정가) | 사용자 입력 가격에 시세 도달 시 자동 체결 (자체 매칭) | 가격 입력 활성, 현재가 대비 ± 표시 |

자체 매칭은 NestJS WS hub의 tick 이벤트에서 가격 도달 시 `execute_trade` RPC 호출 → 체결.
세부 규약은 [trade-rpc.md](./trade-rpc.md) 참조.

## 7. 면책 표기

- 모든 분석/지표 표시 화면 하단: "교육·학습 목적의 모의투자입니다. 투자 권유 아님."
- 매수/매도 추천 일체 금지(현재가/지표 표시는 가능).

## 8. 시장 시간 처리 (MVP 제외)

- MVP는 장 마감 검증 없음 — 24/7 체결 가능.
- 향후 W7+에서 KR 정규장(09:00~15:30 KST) 외 LIMIT 주문 대기 처리 검토.

## 이유

- KR 사용자는 빨강=상승 인지가 깊다 — 반전하면 인지 부조화.
- 호가창 제거로 라이선스 위험 + KIS API 한도 부담 ↓.
- 시장가/지정가만 있어도 학습 목적 충분.
