# 작업 로그 — 2026-05-20

> W2(Claude Code 워크플로 셋업)의 모바일 기반 작업을 마무리하고, W3(Auth) 진입 직전까지 정리한 날.

## TL;DR

오늘은 **모바일 앱의 모든 기반 인프라**를 깔았다. 위에서부터 아래로:

1. **GitHub 워크플로 정착** — PM·DevOps 에이전트와 `/create-pr` 스킬을 GitHub Issues/PR 기반으로 갈아끼움 (Jira·Bitbucket 흔적 제거).
2. **모바일 UI 토큰 시스템** — NativeWind v4 + 디자인 토큰 단일 출처 (`tailwind.config.js`).
3. **모노레포 도메인 타입** — `@tickr/shared`에 zod 스키마/KIS 응답 타입/에러 코드를 cross-app으로 공유.
4. **FSD `shared` 레이어** — `apps/mobile/src/shared/{lib,ui,api,config}` 골격 + RN-only 격리 래퍼.
5. **API/상태 인프라** — axios + react-query + SecureStore 토큰 저장소.
6. **자동 가드** — lefthook `pre-commit`에 typecheck/lint + 디자인 토큰·queryOptions·RN-only 격리 위반 검사.

총 **8개 작업 브랜치**가 develop에 머지됐고, 모든 typecheck/build 통과 상태. W3(Supabase Auth + JWT Guard)부터는 entity/feature 작성 단계로 진입한다.

## 2. PM·DevOps 에이전트 + create-pr GitHub override

> 파일: `.claude/agents/pm.md`, `.claude/agents/devops.md`, `.claude/commands/create-pr.md`

### 왜
글로벌 `~/.claude/agents/pm.md`·`devops.md`는 Jira/Bitbucket 기반인데, Tickr는 **GitHub Issues + GitHub PR**만 쓴다. atlassian API/Jira 키 패턴(`HSD-123`)을 호출하면 그냥 에러가 나니까 프로젝트 레벨에서 통째로 교체.

### 기능
- **`pm.md`** — `#{N}` GitHub Issue를 입력원으로 받아 `gh issue view {N} --json …`으로 본문/코멘트/라벨/마일스톤 수집. FSD 레이어 기준으로 작업 분해(WBS) 만들고 AC를 issue 산출물 체크리스트에 정렬.
- **`devops.md`** — 브랜치 prefix로 PR base 자동 라우팅(`hotfix/*`→master, 그 외→develop). 커밋 로그/diff 분석 후 `gh issue comment` + `/create-pr` 호출. **자동 실행 금지** (항상 `AskUserQuestion`로 승인 게이트).
- **`create-pr.md`** — `gh pr create`/`gh pr edit` 통일 포맷. 한국어 PR 제목, PR 템플릿(`.github/PULL_REQUEST_TEMPLATE.md`)의 rules 체크박스 자동 채움.

### 후속
- 사용자 셋업 1회: `! brew install gh && gh auth login` (아직 실행 전).
- `gh` 설치 후 라벨/마일스톤 동기화: `task-register` 스킬 부트스트랩 따라.

## 3. NativeWind v4 + 디자인 토큰

> 파일: `apps/mobile/tailwind.config.js`, `global.css`, `babel.config.js`, `metro.config.js`, `nativewind-env.d.ts`, `app/_layout.tsx`

### 왜
모바일 UI를 토큰 기반으로 가져가야 다크/라이트 전환이 한 곳에서 끝난다. shadcn/ui는 Radix DOM 의존이라 RN 호환 X — NativeWind v4 단독.

### 토큰 (`tailwind.config.js`)
- **시장 컬러** — `up`(빨강 `#FF3B30`), `down`(파랑 `#0A84FF`), `flat`(회색). **반전 금지** (KR 표준, `.claude/rules/kr-finance.md`).
- **표면** — `bg`/`surface`/`surface-2`/`border` (다크: `bg`=#000, 라이트: `bg`=#FFF).
- **텍스트** — `text`/`text-muted`/`text-disabled`.
- **액션** — `primary`(#0A84FF), `danger`(#FF453A). **매수/매도 버튼은 `primary`가 아닌 `up`/`down`**.
- **타이포** — `title-lg`/`title`/`body`/`caption`/`price-lg`/`price`/`mono-sm`. 가격 텍스트는 `tabular-nums` 폰트 variant 필수 (자릿수 변동 시 흔들림 방지).
- **라운드** — `rounded-xl`(12px) 카드, `rounded-lg`(8px) 칩.
- **보더** — `border-hairline` (RN `hairlineWidth`).

### 인프라
- `babel.config.js` — `nativewind/babel` preset + `jsxImportSource=nativewind`.
- `metro.config.js` — 기존 pnpm 모노레포 워치 + `withNativeWind(config, { input: './global.css' })`.
- `nativewind-env.d.ts` — `className` prop 타입 선언.
- `app/_layout.tsx` — `import '../global.css'` 추가로 Tailwind 디렉티브 로드.

### 검사
`grep -rn '#[0-9A-Fa-f]\{3,6\}' apps/mobile/src/{entities,features,widgets,pages}` 결과가 0이어야 함. lefthook이 이걸 자동화한다(아래 6절).

## 4. `@tickr/shared` 도메인 스키마

> 파일: `packages/shared/src/{enums,kis-types,api-errors}.ts`, `packages/shared/src/schemas/{symbol,quote,account,holding,trade,pending-order}.ts`, `index.ts`

### 왜
모바일과 API 양쪽이 같은 도메인 객체를 다루는데 타입이 양쪽에 분산되면 결국 어긋난다. **단일 출처는 `@tickr/shared`**. 순수 TS + zod로만 구성(react/RN/nestjs 런타임 의존 금지).

### enums
- `OrderSide`(BUY/SELL), `OrderType`(MARKET/LIMIT), `PendingOrderStatus`(OPEN/FILLED/CANCELLED), `Market`(KR/US), `Currency`(KRW/USD).
- `TradeErrorCode` — `.claude/rules/trade-rpc.md`의 에러 코드와 동기화: `INSUFFICIENT_CASH`, `INSUFFICIENT_QTY`, `QUOTE_UNAVAILABLE`, `SYMBOL_INACTIVE`, `PRICE_INVALID`, `ORDER_NOT_FOUND`.

### schemas (zod)
| 파일 | 타입 |
|---|---|
| `symbol.ts` | `SymbolSearchResult`, `SymbolDetail`, `SymbolSearchQuery` |
| `quote.ts` | `Quote`(price/prevClose/delta/ratio/volume/ts), `Candle`(TradingView 호환 `time: epoch s`), `CandleInterval`(`1m`~`1d`), `CandleQuery` |
| `account.ts` | `Account`(가상 현금 잔고) |
| `holding.ts` | `Holding`, `HoldingWithValuation`(서버가 현재가 결합해 반환) |
| `trade.ts` | `Trade`(체결 이력), `ExecuteTradeBody`(LIMIT일 때 price 필수 `superRefine`) |
| `pending-order.ts` | `PendingOrder`(지정가 대기 주문) |

### KIS 응답 타입 (`kis-types.ts`)
- `KisTokenResponse`, `KisQuoteResponse`(`output.stck_prpr` 같은 도메인 약어 그대로), `KisCandleResponse`, `KisWsRawTick`.
- KIS raw 응답은 서버에서 도메인 타입으로 매핑한 다음 모바일에 전달 — 모바일은 `Quote`/`Candle`만 본다.

### api-errors
- `ApiError`(공통), `TradeError`(`code`를 `TradeErrorCode`로 좁힌 변형).

`index.ts` barrel로 모두 노출. `pnpm --filter @tickr/shared build` 통과 확인.

## 5. FSD `shared/lib` (도메인 무지 헬퍼 + RN-only 격리)

> 파일: `apps/mobile/src/shared/lib/{format,platform,cn,storage,index}.ts`

향후 `apps/web` 확장을 대비해 **RN/Expo 전용 API는 `shared/lib`에만** 격리. entity/feature/widget/page에서 `expo-*`·`react-native`를 직접 import하면 lefthook이 차단(6절).

### `format.ts` — KR 증권 포매터
- `formatPrice(value, currency)` — KRW: `₩72,400`(정수), USD: `$185.20`(소수 2자리). Intl 사용.
- `formatPriceNumber(value, currency)` — 통화 기호 없이 숫자만.
- `formatChange({ delta, ratio, currency })` — `▲ 1,200 (+1.69%)` / `▼ 1,200 (-1.69%)` / `- 0 (0.00%)`. 화살표 + 부호 포함.
- `formatPercent(ratio, digits)` — `+1.69%`.
- `formatVolume(n, { abbreviate })` — `1,234,567` 또는 `1.23M`.
- `formatQuantity(qty)` — 정수면 그대로, 소수면 trailing zero 제거.
- `changeDirection(delta)` → `'up' | 'down' | 'flat'` — 색상 토큰 매핑에 사용.

### `platform.ts` — Platform.OS 래퍼
- `isIOS`/`isAndroid`/`isWeb`/`isNative` 상수.
- `platformSelect({ ios, android, web, default })` — `Platform.select`의 default 보장 형태.

### `cn.ts` — className 머지
- `cn(...inputs)` — truthy만 공백 join. clsx 의존성 없이 자체 구현.

### `storage.ts` — SecureStore 래핑
- `storage.get/set/remove(key)` — `expo-secure-store` 비동기 래핑.
- `supabaseStorageAdapter` — `@supabase/supabase-js`의 `auth.storage`에 그대로 꽂을 수 있는 어댑터(W3에서 사용).

`shared/lib/index.ts` barrel에서 모두 노출. entity/feature는 `@/shared/lib`만 import.

## 6. FSD `shared/ui` (도메인 무지 프리미티브)

> 파일: `apps/mobile/src/shared/ui/{Text,Screen,Card,Button,Input,Sheet,Skeleton,EmptyState,index}.tsx`

도메인 표시 컴포넌트(`PriceText`, `SymbolRow` 등)는 **entity로 분리**. 여기엔 도메인 무지 컴포넌트만.

| 컴포넌트 | 핵심 prop | 설명 |
|---|---|---|
| `Text` | `variant` / `tone` / `tabular` | 타이포 토큰 + 다크/라이트 자동 색상. 가격은 `tabular` prop으로 `tabular-nums` 폰트 variant 강제. |
| `Screen` | `edges` / `padded` | `SafeAreaView` + `bg` 토큰. 화면 가장자리 패딩(`px-screen-px`) 자동. |
| `Card` | — | `surface` 배경 + hairline 보더 + `rounded-xl`. 그림자 안 씀. |
| `Button` | `variant`(primary/up/down/ghost/danger) / `size` / `loading` | 매수=up, 매도=down. loading은 `ActivityIndicator`. |
| `Input` | `label` / `helper` / `error` | TextInput + placeholder 색상 자동 + error 상태 토큰. |
| `Sheet` | `visible` / `onClose` / `showHandle` | RN `Modal` 기반 바텀시트. 향후 `@gorhom/bottom-sheet` 도입 검토. |
| `Skeleton` | — | Animated opacity 펄스. 토큰 배경. |
| `EmptyState` | `title` / `description` / `action` | 리스트/검색 결과 없을 때. |

### tsconfig 변경
`apps/mobile/tsconfig.json`의 `paths`에 `"@/*": ["./src/*", "./*"]`로 src 우선 + 기존 fallback. 기존 Expo 템플릿의 `@/hooks/use-color-scheme` 같은 경로도 깨지지 않게 점진 마이그레이션 형태.

## 7. API/상태 인프라 (`shared/api` + `shared/config`)

> 파일: `apps/mobile/src/shared/{api,config}/*`, `apps/mobile/src/app/providers/QueryProvider.tsx`

### `shared/config/env.ts` — 환경변수 단일 출처
- `EXPO_PUBLIC_*` 만 읽음. 누락 시 throw로 빠른 실패.
- `env.apiUrl`, `env.wsUrl`, `env.supabaseUrl`, `env.supabaseAnonKey`, `env.appEnv`.
- **비밀키(`SUPABASE_SERVICE_ROLE_KEY`, `KIS_APP_SECRET` 등) 절대 금지** — 클라 번들 노출.

### `shared/config/react-query.ts` — 기본 옵션
- `staleTime: 60_000` (시세는 WS push이므로 폴링 불필요).
- `gcTime: 5분`.
- `retry`: 4xx면 즉시 포기, 그 외 최대 2회.
- `refetchOnWindowFocus: false`, `refetchOnReconnect: 'always'`.
- mutation `retry: false`.

### `shared/api/client.ts` — axios 인스턴스
- `baseURL = env.apiUrl`, timeout 10초.
- **요청 인터셉터** — `tokenStorage`에서 accessToken 가져와 `Authorization: Bearer ...` 자동 첨부.
- **응답 인터셉터** — 현재는 에러를 그대로 throw(호출처 처리). W3에서 401 자동 로그아웃 확장 예정.
- `tokenStorage` — `tickr.accessToken` 키로 SecureStore 저장.

### `shared/api/query-client.ts`
- 전역 `queryClient` 단일 인스턴스(`queryDefaults` 적용).

### `src/app/providers/QueryProvider.tsx`
- `QueryClientProvider` 래퍼. 앱 루트(`app/_layout.tsx`)에서 한 번만 import해 사용 예정(아직 router에 꽂지 않음 — W3 진입 시).

### 의존성 추가
- `axios`
- `@tanstack/react-query`
- `expo-secure-store`

## 8. lefthook (자동 가드)

> 파일: `lefthook.yml`, `package.json`(`prepare` script)

사용자 요청: **버그 코드가 develop에 진입하지 않도록 매 커밋 전에 자동으로 막을 것**.

### pre-commit (병렬 실행)
| 작업 | 동작 | 실패 시 메시지 |
|---|---|---|
| `typecheck` | `pnpm typecheck`(turbo cache로 1~2초) | "타입 에러 — 수정 후 다시 커밋하세요" |
| `lint` | 변경 ts/tsx/js/jsx 있을 때 `pnpm lint` | "lint 에러 — 수정 후 다시 커밋하세요" |
| `no-hardcoded-colors` | `apps/mobile/src/**`에 hex 색상(`#xxx`) 검출 시 차단 | "디자인 토큰 위반 — hex 대신 className 토큰 사용" |
| `no-inline-querykey` | `pages/widgets/features`에서 `queryKey: [` 검출 시 차단 | "queryOptions 팩토리 패턴 위반" |
| `no-rn-only-in-entity` | `entities/features/widgets/pages`에서 `expo-secure-store/haptics/router/web-browser/linking` 직접 import 검출 시 차단 | "RN-only 모듈 격리 위반" |

### pre-push (병렬)
- `build-shared` — `@tickr/shared` 빌드 통과 보장.

### 활성화
- `pnpm install` 시 `prepare` script가 `lefthook install` 자동 실행.
- 수동 활성: `pnpm exec lefthook install`.
- 임시 우회: `LEFTHOOK=0 git commit ...` (가급적 금지 — PR 리뷰에서 차단).

### 이미 확인
- `pnpm exec lefthook run pre-commit`으로 typecheck 통과 검증.

7. **테스트 페이지** — 임시 `/whoami` 화면에서 현재 사용자 표시

### 잔여 정리
- `apps/mobile`의 `components/`, `hooks/`, `constants/`, `scripts/`(기존 Expo 템플릿)은 점진적으로 `src/` 하위 FSD 구조로 마이그레이션. W3 진행하면서 자연스럽게.

## 12. 메모

- 모든 머지는 `--no-ff`로 진행해 머지 커밋이 남는다. (`git log --graph --all`로 흐름 보기 좋게)
- 오늘 push 거부 한 번 — GitHub에서 NativeWind PR을 직접 머지한 commit(`ae75a14`)이 origin/develop에 들어와 있어 local과 diverged. `git pull --no-rebase`로 통합 후 정상화.
- 커밋 메시지에 `Constraint:`/`Rejected:`/`Confidence:`/`Scope-risk:`/`Directive:`/`Not-tested:` 트레일러를 일관 적용했다(`~/.claude/CLAUDE.md`의 `commit_protocol`). 결정의 배경이 깃 히스토리에 남는다.
